# Git · Primeiros comandos

Material inicial para estudar a sequência de criação e publicação de um repositório.

| Comando | Finalidade |
| --- | --- |
| `git init` | Criar um repositório local |
| `git add .` | Preparar arquivos para commit |
| `git commit` | Registrar alterações |
| `git branch -M main` | Nomear a branch |
| `git remote add origin` | Associar um repositório remoto |
| `git push -u origin main` | Publicar e configurar o acompanhamento |

O arquivo `git-auto.sh` é o exemplo original e contém a URL de `ApontiTestes`. Leia-o como material de estudo: não execute dentro deste repositório consolidado, pois ele altera branch e remote.

## O que foi praticado

Versionamento inicial e diferença entre operações locais e envio ao remoto. Este laboratório não contém uma suíte de testes automatizados.
