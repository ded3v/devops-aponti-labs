- Sintaxe do servidor Node.

- HTTP 200 nas rotas / e /health.
- HTTP 503 em /ready sem banco disponível, sem exposição de credenciais.
- HTTP 404 para rota inexistente e 405 para método não permitido.
- Encerramento do servidor com SIGTERM.
- .env ignorado pelo Git e .env.example incluído.
- Senhas locais ausentes dos arquivos destinados ao versionamento.
- .env.example sem valores preenchidos.
- npm audit --omit=dev sem vulnerabilidades reportadas na consulta.
